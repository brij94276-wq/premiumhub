# PremiumHub — Simple Static Store

## 1. Files
- `index.html` — website
- `style.css` — design
- `script.js` — products, prices, WhatsApp number and UPI ID
- `qr.png` — put your own UPI QR here

## 2. Change your details
Open `script.js` and change:
- `WHATSAPP_NUMBER`
- `UPI_ID`
- product prices

Use your WhatsApp number in international format without `+` or spaces.
Example: `919876543210`

## 3. Add your QR
Replace `qr.png` with your own UPI QR image. Keep the filename exactly `qr.png`.

## 4. Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files.
3. Open repository Settings → Pages.
4. Select the branch containing the files and save.
5. GitHub will provide your public website URL.

## Important
Only sell accounts/subscriptions that you are legally and contractually authorized to resell or transfer. Many services prohibit account resale or credential sharing. Verify each service's current terms before listing it.
